## 分词算法详解

### 实现原理
```javascript
_tokenize(text) {
  // 1. 提取英文词和数字：HIIT, 60, 30
  // 2. 提取2-4字中文词组：生酮饮食, 生酮, 饮食
  // 3. 提取单个中文字：生, 酮, 饮, 食
  // 4. 去重
}
```

### 评分机制
- 关键词出现次数 × 词长权重
- 长词（>1字符）权重 = 2
- 单字词权重 = 1
- 示例："生酮饮食"匹配"生酮饮食"得分 = 1×2 = 2

### 效果验证
```
查询: "生酮饮食"
分词结果: ["生酮饮食", "生酮", "酮饮", "饮食", "生", "酮", "饮", "食"]
匹配文档: "生酮饮食（Ketogenic Diet）是一种..."
分数计算: 1×(生酮饮食×2) + 1×(生酮×2) + ... = 20分 ✅
```
