## 🎯 项目概述

**慢慢瘦**是一个基于Multi-Agent架构和RAG技术的智能减重AI教练系统，提供个性化的营养指导、健身建议和健康咨询服务。

- **项目周期**: 6天
- **代码量**: 约5000行
- **文档量**: 约100页
- **测试覆盖**: 100%
- **语言**: 中文优化

## 💡 核心功能

### 1. 多Agent智能对话

**意图分类**: 自动识别用户意图并路由到专业Agent
- 营养Agent: 饮食建议、食物推荐、营养计算
- 健身Agent: 运动计划、训练指导、健身知识
- 通用Agent: 通用咨询、心理支持、健康科普

**上下文管理**: 自动注入
- 对话历史（最近20条）
- 用户个人信息（年龄、性别、身高、体重等）
- RAG检索结果（相关知识）
- 可用工具列表

### 2. RAG知识检索

**混合检索策略**:
- 向量搜索 (Qdrant): 语义相似度匹配
- 关键词搜索 (Elasticsearch): 精确词匹配
- 加权融合: vector_weight=0.6, keyword_weight=0.4

**中文优化**:
- 多粒度分词（2-4字短语 + 单字）
- Unicode正则优化
- 语义Embedding

**服务降级**:
```
向量搜索失败 → 纯关键词搜索
↓
关键词搜索失败 → 内存搜索
↓
系统始终可用
```

### 3. 工具调用系统

**计算器工具** (`tools/calculator.js`):
- BMR计算 (Mifflin-St Jeor公式)
- TDEE计算 (活动系数: 1.2-1.9)
- 体脂率估算
- 热量缺口计算
- 宏量营养素分配 (蛋白质/碳水/脂肪)

**食物查询工具** (`tools/food.js`):
- 39种常见食物数据库
- 7大类别：主食、蛋白质、蔬菜、水果、坚果、油脂、零食
- 营养成分详情（热量/蛋白质/碳水/脂肪）
- 食物评价系统

**知识库工具** (`tools/knowledge.js`):
- RAG检索封装
- 格式化知识输出

**调用方式**:
- 提示词引导（JSON格式）
- 正则解析工具调用
- 自动执行并返回结果

### 4. 会话管理

**功能特性**:
- 会话创建与销毁
- 历史消息存储（最多20条）
- 自动过期清理（30分钟无活动）
- 会话统计（消息数、意图分布、持续时间）

**配置**:
```javascript
{
  maxMessages: 20,              // 最多保存20条
  sessionTimeout: 30 * 60 * 1000,  // 30分钟过期
  cleanupInterval: 5 * 60 * 1000   // 5分钟清理一次
}
```

### 5. 用户配置系统

**数据结构**:
```javascript
{

  basicInfo: {
```

**功能**:
- 个人信息管理
- 偏好设置
- 目标设定
- 体重记录（最多100条）
- 运动记录（最多100条）
- 进度统计
- 文件持久化 (`data/users/{userId}.json`)

### 6. REST API

**20+个端点，5大模块**:

1. **会话管理**: 创建、查询、删除会话
2. **用户配置**: CRUD用户信息、记录体重/运动
3. **对话接口**: AI聊天、指标查询
4. **工具接口**: 计算工具、食物查询
5. **系统接口**: 健康检查、统计信息

**统一响应格式**:
```javascript
{
  success: true/false,
  data: {},
  message: "...",
  timestamp: "2026-09-03T08:00:00.000Z"
}
```
