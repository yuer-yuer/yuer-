## 食物搭配原则

### 原则1：蛋白质 + 纤维 = 强饱腹感

**科学依据：**
- 蛋白质消化慢，食物热效应高（消耗热量的30%用于消化）
- 纤维吸水膨胀，延长胃排空时间

**示例搭配：**
- 鸡胸肉150g + 西兰花300g
- 煮鸡蛋2个+ 黄瓜沙拉200g
- 希腊酸奶150g + 奇亚籽15g

### 原则2：低GI碳水 + 蛋白质/脂肪 = 稳血糖

**科学依据：**
- 蛋白质和脂肪延缓碳水吸收
- 避免血糖过山车（饿得快、易疲劳）

**示例搭配：**
- 燕麦50g + 鸡蛋2个 + 杏仁10粒
- 红薯100g + 煎鳕鱼150g
- 全麦面包 + 牛油果 + 荷包蛋

### 原则3：彩虹蔬菜原则

**每餐至少3种颜色：**
- 绿色（菠菜、西兰花）→ 叶绿素、镁
- 红色（番茄、辣椒）→ 番茄红素
- 黄色（胡萝卜、南瓜）→ β-胡萝卜素
- 紫色（紫甘蓝、茄子）→ 花青素
- 白色（蘑菇、花椰菜）→ 多糖

### 原则4：避免"空热量"食物

**空热量 = 高热量 + 低营养密度**

| 劣质食物 | 热量 | 替代方案 | 热量 |
|---------|------|---------|------|
| 薯片100g | 550kcal | 空气炸锅红薯条100g | 130kcal |
| 可乐500ml | 215kcal | 气泡水 + 柠檬 | 0kcal |
| 奶油蛋糕100g | 350kcal | 希腊酸奶 + 蓝莓 | 120kcal |
| 白米饭200g | 232kcal | 糙米饭200g | 222kcal（营养多3倍） |

## 减脂期一周食谱规划

### 周一至周五（工作日）

**早餐轮换：**
1. 燕麦 + 鸡蛋 + 水果
2. 全麦面包 + 牛油果 + 火腿
3. 希腊酸奶 + 坚果 + 香蕉
4. 红薯 + 煮鸡蛋 + 蔬菜汁
5. 藜麦粥 + 蛋白粉 + 蓝莓

**午餐模板：**
- 蛋白质150-200g（鸡/鱼/牛肉轮换）
- 主食80-100g（糙米/红薯/全麦意面）
- 蔬菜300g+

**晚餐原则：**
- 无主食或少量主食
- 蛋白质为主
- 大量蔬菜

### 周末（可适当放松）

**周六：** 
- 早午餐Brunch：全麦班尼迪克蛋 + 果汁
- 晚餐：火锅（选瘦肉、海鲜、蔬菜，少蘸酱）

**周日：**
- 家庭聚餐：正常吃，但控制份量（八分饱）
- 晚餐：清淡蔬菜餐，平衡周末摄入

## 外出就餐指南

### 中餐厅

**✅ 推荐点餐：**
- 清蒸鱼 / 白灼虾
- 手撕鸡 / 盐焗鸡（去皮）
- 蒜蓉西兰花 / 清炒时蔬
- 紫菜蛋花汤

**❌ 避免：**
- 糖醋、红烧、干锅类（高糖高油）
- 炒饭、炒面（油多）

### 日料

**✅ 推荐：**
- 刺身拼盘
- 寿司（选简单款，少米饭）
- 烤鱼 / 烤鸡肉串
- 味噌汤 / 沙拉

**❌ 避免：**
- 天妇罗（油炸）
- 拉面（高钠高油）

### 西餐

**✅ 推荐：**
- 牛排（菲力、西冷）
- 烤鸡胸 / 烤三文鱼
- 蔬菜沙拉（酱汁另上）

**❌ 避免：**
- 奶油浓汤
- 意面（酱汁高油）
- 甜点

### 快餐

**✅ 推荐：**
- Subway：全麦面包 + 烤鸡胸 + 多蔬菜
- 麦当劳：板烧鸡腿堡（去酱）
- 沙拉轻食店

**❌ 避免：**
- 炸鸡汉堡
- 薯条 / 可乐

## 常见问题

**Q1：能吃水果吗？**
A：可以，但要控制量。推荐低GI水果：苹果、蓝莓、柚子、草莓。每天200-300g。避免高糖水果：香蕉、葡萄、荔枝。

**Q2：晚上饿了怎么办？**
A：
- 喝一大杯水（有时是假性饥饿）
- 吃低热量食物：黄瓜、番茄、无糖酸奶
- 如果实在饿，说明晚餐蛋白质不够

**Q3：可以吃零食吗？**
A：推荐"减脂零食"：
- 水煮蛋
- 无糖酸奶
- 坚果（10-15粒）
- 圣女果、黄瓜
- 海苔

**Q4：怎么判断食物热量？**
A：使用App（薄荷健康、MyFitnessPal）扫码或搜索，前两周认真记录，后续就能估算了。

## 总结

减脂饮食的核心：
1. **高蛋白**（增加饱腹感 + 保护肌肉）
2. **低GI碳水**（稳定血糖 + 持续能量）
3. **适量优质脂肪**（激素平衡 + 吸收维生素）
4. **大量蔬菜**（纤维 + 微量元素）
5. **充足饮水**（代谢废物 + 假性饥饿）

记住：没有"超级食物"，只有"合理搭配"！
